# Smile Bead releases

Signed builds of **Smile Bead**, the desktop companion. This repository holds only the built program (no source code): one release per version, each with `SmileBead.zip`, `SmileBead.exe` and `SmileBead-update.txt`.

Installed copies of Smile Bead (2.8.63 and later) update themselves from here. They only install an update whose version summary is signed with the Smile Bead update key, and whose program matches the SHA256 in that summary.

To install by hand: download `SmileBead.exe` from the [latest release](../../releases/latest) and run it (no installer, no admin rights).
